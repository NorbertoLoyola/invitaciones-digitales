# Aniversario

Categoría nueva — bodas de plata/oro, aniversarios de pareja.

| Carpeta | Estilo | Animación protagonista | Estado |
|---|---|---|---|
| `carrusel/` | Vino/blush/dorado, romántico | Carrusel de fotos "Nuestra historia" con swipe nativo (`scroll-snap`), flechas y puntos de navegación sincronizados | Generado |

Mismo motor `CONFIG`, con un array nuevo `CONFIG.momentos` (año + texto) que arma el carrusel dinámicamente — pensado para contar la línea de tiempo de la pareja en vez de una galería de fotos sueltas.
